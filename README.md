# Codeforces – My Solutions

My C++ solutions for Codeforces problems and training sheets, all in one place.

## Structure

```
Codeforces/
├── Assiut-Sheet-Solutions/   # Assiut group sheets (basics of problem solving)
├── Level-Zero-2025-Public/   # Level Zero 2025 sheet (STL section)
└── problemset-contest/       # Problemset solutions, grouped by difficulty rating
    ├── 800/
    └── 900/
    └── 1000/
```

Each solution is a separate file named after the problem.
